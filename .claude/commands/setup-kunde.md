# Kunden-Setup Assistent

Du bist ein Einrichtungsassistent für das Botpress Webchat Plugin. Du führst den Entwickler Schritt für Schritt durch die Einrichtung eines neuen Kunden-Bots.

## Ablauf

### Schritt 1: Credentials prüfen

Lies die Datei `plugin/developer-config.php` (falls vorhanden) und zeige die gespeicherten Default-Werte:
- `botpress_pat`
- `workspace_id`

Frage den Benutzer:
> **Sollen die Standard-Credentials verwendet werden?**
> - PAT: `bp_p...xxxx` (maskiert anzeigen, nur erste 4 + letzte 4 Zeichen)
> - Workspace: `wkspace_...`
>
> (j/n) — Oder neue Werte eingeben?

Wenn nein → frage nach PAT und Workspace ID.

### Schritt 2: Kunden-Daten abfragen

Frage nacheinander:
1. **Kundenname** (z.B. "IBD Wickeltechnik") — wird als Bot-Name und companyName verwendet
2. **Sprache** (de/en/fr, Standard: de)

### Schritt 3: Bot in Botpress Cloud erstellen

Frage: **Bot erstellen für "{KUNDENNAME}"? (j/n)**

Erstelle den Bot via Botpress API:

```bash
curl -s -X POST "https://api.botpress.cloud/v1/admin/bots" \
  -H "Authorization: Bearer {PAT}" \
  -H "x-workspace-id: {WORKSPACE_ID}" \
  -H "Content-Type: application/json" \
  -d '{"name": "{KUNDENNAME}"}'
```

Aus der Response `bot.id` extrahieren. Zeige:
> Bot erstellt: `{BOT_ID}`

### Schritt 4: Agent deployen

1. Sichere die aktuelle `agent/agent.json`:
   ```bash
   cp agent/agent.json agent/agent.json.bak
   ```

2. Schreibe die neue Bot ID in `agent/agent.json` (mit dem Write-Tool).

3. Setze die Production-Config mit `--prod` Flag:
   ```bash
   cd agent
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set wordpressBaseUrl "http://placeholder.local/wp-json" --prod
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set wpApiToken "placeholder" --prod
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set companyName "{KUNDENNAME}" --prod
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set language "{SPRACHE}" --prod
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set sendgridApiKey "placeholder" --prod
   "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" config:set sendgridFromEmail "bot@placeholder.local" --prod
   ```
   WICHTIG: `config:set` ohne `--prod` setzt nur die Dev-Config. Deploy braucht `--prod`.
   Die Werte `wordpressBaseUrl`, `wpApiToken`, `sendgridApiKey`, `sendgridFromEmail` sind Platzhalter — 
   sie werden später vom Plugin mit den echten Werten überschrieben (Auto-Register).

4. Führe den Deploy aus:
   ```bash
   cd agent && echo "y" | "C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe" deploy
   ```
   Falls der Deploy wegen "Raw mode not supported" fehlschlägt, bitte den Benutzer den Deploy 
   manuell in einem separaten Terminal auszuführen:
   ```
   cd C:\Users\skuehne\Desktop\Projekt\botpress-adk\agent
   C:\Users\skuehne\AppData\Local\Programs\adk\adk.exe deploy
   ```
   Warte dann auf Bestätigung vom Benutzer.

5. Stelle die originale `agent/agent.json` wieder her:
   ```bash
   cp agent/agent.json.bak agent/agent.json && rm agent/agent.json.bak
   ```
   WICHTIG: Auch bei Fehlern immer wiederherstellen!

### Schritt 5: Webchat ID ermitteln

Nach dem Deploy hat der Bot eine Webchat-Integration. Ermittle die Webchat ID:

```bash
curl -s "https://api.botpress.cloud/v1/admin/bots/{BOT_ID}" \
  -H "Authorization: Bearer {PAT}" \
  -H "x-workspace-id: {WORKSPACE_ID}"
```

Aus der JSON-Response die Webchat-Integration finden und deren `webhookId` extrahieren:
- Suche in `bot.integrations` nach dem Eintrag mit `"name": "webchat"`
- Nimm dessen `webhookId` als Webchat ID

Falls Python verfügbar:
```bash
| python3 -c "import sys,json; d=json.load(sys.stdin); [print(v['webhookId']) for v in d['bot']['integrations'].values() if v.get('name')=='webchat']"
```

Falls nicht, parse manuell mit grep:
```bash
| grep -oP '"webhookId":"[^"]*"' 
```

### Schritt 6: developer-config.php erstellen

Erstelle die Datei `output/{KUNDENNAME_SLUG}/developer-config.php`:

(KUNDENNAME_SLUG = Kundenname mit Bindestrichen statt Leerzeichen, z.B. "IBD-Wickeltechnik-GmbH")

```php
<?php
/**
 * Developer Configuration — {KUNDENNAME}
 * Generated by /setup-kunde
 */
return [
    'botpress_pat'     => '{PAT}',
    'workspace_id'     => '{WORKSPACE_ID}',
    'bot_id'           => '{BOT_ID}',
    'webchat_id'       => '{WEBCHAT_ID}',
    'default_language'  => '{SPRACHE}',
];
```

### Schritt 7: ZIP erstellen

Erstelle ein ZIP-Archiv mit dem Plugin + der Config:

```bash
mkdir -p output/{KUNDENNAME_SLUG}/botpress-webchat
# Plugin-Dateien kopieren (ohne node_modules, ohne .git)
cp -r plugin/includes plugin/src plugin/build plugin/botpress-webchat.php plugin/uninstall.php plugin/composer.json plugin/package.json output/{KUNDENNAME_SLUG}/botpress-webchat/
# developer-config.php mit Kundenwerten rein
cp output/{KUNDENNAME_SLUG}/developer-config.php output/{KUNDENNAME_SLUG}/botpress-webchat/
```

ZIP mit PowerShell erstellen (Windows):
```bash
cd output/{KUNDENNAME_SLUG} && powershell.exe -Command "Compress-Archive -Path 'botpress-webchat' -DestinationPath '../{KUNDENNAME_SLUG}-botpress-webchat.zip' -Force"
```

WordPress erkennt den Plugin-Ordner am Verzeichnisnamen `botpress-webchat` im ZIP.

### Schritt 8: Zusammenfassung

Zeige dem Benutzer:

```
Kunden-Setup abgeschlossen!

Kunde:      {KUNDENNAME}
Bot ID:     {BOT_ID}
Webchat ID: {WEBCHAT_ID}
Sprache:    {SPRACHE}

ZIP-Datei:  output/{KUNDENNAME_SLUG}-botpress-webchat.zip

Der Kunde muss:
1. Plugin in WordPress installieren (ZIP hochladen)
2. Aktivieren
3. Fertig — Bot ist automatisch verbunden
```

## Wichtig
- Frage IMMER nach Bestätigung bevor du den Bot erstellst oder deployest
- Bei Fehlern: zeige die Fehlermeldung und frage ob der Benutzer es erneut versuchen will
- Stelle die `agent/agent.json` IMMER wieder her, auch bei Fehlern
- Verwende IMMER `config:set --prod` (nicht ohne --prod)
- Verwende PowerShell `Compress-Archive` für ZIP (kein `zip` Command auf Windows)
- Die output/ Dateien NICHT committen (enthält Secrets)
